Solids

This page preserves the available primitives report, not the current golden gate's execution results. The primitives example (crates/solidcore/examples/primitives) builds each primitive through the public API in pure Rust and checks that it is a closed manifold solid with the analytic Euler-Poincare characteristic, volume, area and bounding box (relative tolerance 1e-09). A primitive that stops at code not ported yet names the unit and upstream symbol it is blocked on.
