solidcore

solidcore is a boundary-representation (B-rep) solid modeling kernel in safe Rust, started as a port of NVIDIA's SMLib from usd-brep (Apache-2.0; reference usd-brep v1.0.1 (3fd5b95)). The C++ is now reading material, not the correctness target. CI checks Rust outputs against committed goldens; a golden proves an output unchanged, not correct. Correctness is established by closed forms, geometric checks and invariants.

Green and partial below are historical port-plan statuses, not current CI verdicts. The 282 units' golden record counts describe stored expectations, never measured passes. See canonical CI for execution results. This page is regenerated from the repository on every push to main.
