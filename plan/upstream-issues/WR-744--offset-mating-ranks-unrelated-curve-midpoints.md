#### WR-744. Offset edge mating ranks unrelated parameter midpoints instead of distances to intersection branches

- **Severity:** Wrong result
- **Area:** Offset geometry creation
- **Location:** `SmOffsetGeometryCreation::MateEdges`; Rust `offset::offset_geometry_creation::OffsetGeometryCreation::mate_edges`, selection among successfully trimmed surface-intersection curves.
- **What happens:** each candidate is ranked by the distance between its parameter midpoint and the original edge's parameter midpoint. The candidate curves need not have corresponding parameterizations or trimmed extents. A geometrically remote branch can therefore rank ahead of the nearby offset. On a continuous helical flank, large temporary extensions also intersect the root cylinder across the screw axis; selecting that continuation leaves a gap that cannot be closed by a segment on the cylinder.
- **Trigger:** a synthetic modeled M20x2.5 shaft, radius 10 and height 20, whose two flank faces span multiple turns, offset by -.1. For one root edge the valid candidate's parameter-midpoint distance is 1.25390, while the remote continuation's is 1.14905. The exact distances from the original reference point to those branches are .11544 and 1.14875 respectively. The wrong curve ends at z 18.85244 instead of meeting the z 20 cap, and the gap closer correctly refuses its off-cylinder chord.
- **How found:** SolidCraft #11582, with continuous flank faces from SolidCraft #11737. Instrumented candidate selection and independent native surface-intersection and nearest-point queries identify the chosen branch; no commercial CAD data is used.
- **Confirmed:** in the Rust implementation. No C++ reference result is claimed.
- **Correction:** edge mating ranks each candidate by the exact closest-point distance from the original edge's reference point over that candidate's **trimmed** interval. The existing strict-less comparison preserves deterministic tie order. Solve errors and missing answers fail the operation; there is no midpoint fallback.
- **Native regression:** the existing geometry-creation unit test uses the same exact rational quarter-circle locus with different Möbius parameterizations and shifted knot intervals. A parallel arc .1 away has a closer parameter midpoint, but is geometrically farther. The corrected ranking is invariant under these parameter changes. A second assertion restricts the candidate's interval before the reference point and verifies that the excluded part cannot influence the ranking.
- **Geometric context:** a curve parameter is not a geometric distance, and independent curves' parameter midpoints need not correspond. This correction reuses the kernel's exact global curve/point minimization; it introduces no mesh decision or new intersection construction.
